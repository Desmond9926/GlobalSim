# GlobalSim 前端界面设计计划

## Summary

前端定位为面向研究分析者的现代 SaaS 风格“全球态势推演工作台”：首页有强视觉中心，但整体克制、可长期阅读和操作。采用左侧导航、桌面优先布局、React + shadcn/ui 组件体系，关系网络使用 React Flow。首版不做世界地图，核心视觉为主体关系网络、风险态势和推演时间线。

## Key Screens

### 1. 世界态势盘

首页采用“关系网络 + 风险态势”布局。

核心模块：

- 中央为 React Flow 关系网络，节点代表 China、USA、Russia、EU、NATO、UN。
- 边代表主体关系，使用颜色和线宽表达友好度、贸易依赖、军事紧张度。
- 右侧或下方展示风险排行榜、关键变量和最近推演入口。
- 顶部展示更新时间、新闻抓取状态、待审事件数量。
- 点击节点显示主体详情：目标、能力指标、近期相关事件、参与推演次数。
- 点击边显示双边关系详情：friendliness、trade_dependency、military_tension。

视觉风格：

- 现代 SaaS，浅色或中性色底色。
- 不使用军事化大屏风格。
- 风险用低调绿/黄/红 Badge、细线和小图标表达。

### 2. 新闻事件页

用于新闻监测、事件抽取和事件修正。

布局：

- 左侧或顶部筛选：来源、时间、抽取状态、主体、领域。
- 主体区域为高密度表格，字段包括标题、来源、发布时间、抽取状态、关联事件、操作。
- 新闻详情抽屉展示摘要、来源链接、抽取结果。
- 事件编辑使用 Dialog 或 Sheet，允许修改 actor、targets、action、domain、intensity、summary、occurred_at。
- 支持从选中新闻触发事件抽取。

### 3. 推演页

推演页采用“全屏时间线 + Agent 响应卡片 + 底部自然语言干预输入框”。

核心体验：

- 顶部显示当前事件摘要、推演轮数、分支名称、运行状态。
- 中央为推演时间线，按 T0/T1/T2/T3/T4 展示。
- 每一轮展示 Agent 响应卡片，而不是矩阵表格。
- Agent 卡片包含：感知、目标、候选行动评分、最终行动、置信度、引用来源。
- 底部固定输入框支持自然语言干预，例如：
  - “纠正：这条新闻只是草案，不是正式政策。”
  - “假设欧盟不跟进制裁。”
  - “让中国在 T1 选择外交抗议而不是产业补贴。”
- 用户提交后，系统先展示解析结果，确认后生成新推演分支。
- 原始推演不覆盖，所有干预结果以分支形式保留，便于对比和回溯。

### 4. 报告页

报告页采用“研究简报”风格，服务于阅读和 Markdown 导出。

内容结构：

- 事件摘要
- 关键判断
- 主体响应
- 推演时间线
- 风险分析
- 关键变量
- 来源链接
- Markdown 导出按钮

报告视觉：

- 以正文阅读为主，辅以少量 Badge、时间线和引用区块。
- 风险同时展示等级、估计百分比和不确定性说明。
- 不展示模型完整内部思考日志，只展示结构化决策摘要。

### 5. 设置页

设置页用于本地原型配置。

配置项：

- 新闻源列表：名称、URL、启用状态。
- LLM 配置提示：provider、model、base_url 是否已配置。
- 默认推演轮数。
- 默认参与 Agent。
- 数据重置或种子数据重新导入入口。

## Navigation And Components

导航结构：

- 左侧导航栏固定。
- 页面包括：态势盘、新闻事件、推演、报告、设置。
- 顶部保留轻量全局状态栏：抓取状态、模型状态、最近更新时间。

主要组件：

- shadcn/ui：Button、Table、Tabs、Dialog、Sheet、Card、Badge、Select、Slider、Textarea、Tooltip、Separator。
- lucide-react：导航、刷新、导出、运行、分支、外链、风险等图标。
- React Flow：关系网络视图。
- 时间线组件：自定义实现，优先保证桌面可读性。
- Agent 响应卡片：固定字段结构，避免自由文本堆叠。

响应式策略：

- 桌面优先，重点适配 1440px 和 1920px。
- 平板和移动端保证可查看、可滚动，不优先优化复杂推演操作。
- 关系网络和推演时间线在小屏上允许横向滚动或切换为列表。

## Interaction Details

关系网络：

- 节点颜色按主体类型区分：国家、组织。
- 边颜色按关系紧张度表达。
- 点击节点或边打开详情侧栏。
- 首页只展示核心 6 个主体，避免首版网络过密。

推演干预：

- 底部输入框为自由文本。
- 系统将自由文本解析为结构化干预。
- 用户必须确认解析结果后才生成新分支。
- 分支命名默认使用时间和干预摘要，例如 `Branch 2026-06-04 EU non-follow`。
- 分支之间可在推演页顶部切换。

风险表达：

- 页面显示风险等级：Low、Medium、High。
- 同时显示模型估计百分比。
- 必须显示不确定性：Low、Medium、High。
- 使用低调色标，不使用强警报风格。

引用来源：

- 新闻、事件和报告中的关键判断保留来源链接级引用。
- 引用显示标题、来源、发布时间、URL。
- 外链用图标按钮打开。

## Test Plan

前端验收场景：

- 打开首页后能看到主体关系网络、风险排行榜和关键变量。
- 点击主体节点后能看到 Agent 目标、能力指标和近期事件。
- 新闻事件页能筛选新闻、查看详情、编辑抽取事件。
- 推演页能展示多轮时间线和 Agent 响应卡片。
- 在底部输入自然语言干预后，能看到结构化解析结果并确认。
- 确认干预后，页面生成新分支，不覆盖原推演。
- 报告页能展示研究简报，并导出 Markdown。
- 桌面 1440px 和 1920px 下主要内容不重叠、不截断。
- 小屏下页面可滚动查看，核心信息不丢失。

## Assumptions

- 首版不做交互式世界地图。
- 首页主视觉为关系网络，不是新闻流或纯推演入口。
- 整体风格为现代 SaaS，避免军事沙盘和深色指挥中心风格。
- Agent 响应用卡片列表展示，不用矩阵表格。
- 推演页以时间线为主，不采用三栏工作台。
- 人工干预采用底部自然语言输入，且确认后生成新分支。
